# Portfolio

Gaurav Sharma's personal site — [leovaldez42.github.io](https://leovaldez42.github.io/).

Original design by [Vineet Arora](https://dribbble.com/vineetarora). Built with Vite, React, TypeScript, and indented SASS.

## Develop

```bash
npm install
npm run dev
```

## Build & deploy

```bash
npm run build
npm run deploy
```

`deploy` publishes `dist` to the `gh-pages` branch.

## Edit content

Update copy, links, and meta in [`src/content.ts`](src/content.ts). Replace assets under `src/assets/` (`me.jpeg`, `resume.pdf`, `cv.pdf`, icons) as needed.
